# Vainah VPN — проверка Rollypay без настоящих денег

Сайт остаётся многостраничным, а кнопки покупки обычных тарифов ПОКА ведут в существующего Telegram-бота. Никаких реальных денег эта версия сайта не принимает.

## Что уже настроено владельцем в Netlify

- `ROLLYPAY_TERMINAL_ID` — есть.
- `ROLLYPAY_API_KEY` — есть, скрытый секрет.
- `ROLLYPAY_SIGNING_SECRET` — есть, скрытый секрет.

Не присылай значения этих переменных в чат, на скриншотах они должны быть закрыты.

## Что нужно добавить перед проверкой

В Netlify > Project configuration > Environment variables > Add a variable > Add a single variable:

**Key:** `ROLLYPAY_TEST_TOKEN`

**Value:** придумай личный длинный случайный пароль (не менее 24 символов). Используй менеджер паролей. Не копируй этот пароль из инструкции.

Включи **Contains secret values**, оставь **All scopes**, нажми **Create variable**.

Этот пароль нужен ТОЛЬКО тебе, чтобы посторонние не создавали тестовые счета на твоей кассе.

## Как разместить Netlify Functions (ВАЖНО)

Обычная повторная загрузка набора HTML-файлов через Netlify Drop — недостаточный способ для гарантированной установки Functions. Нужен Git-based deployment / полноценный build или Netlify CLI.

### Вариант с GitHub

1. Создай **приватный** репозиторий GitHub и помести в него **содержимое папки проекта**, чтобы в корне были `netlify.toml`, `package.json`, `site/` и `netlify/functions/`.
2. В Netlify открой существующий проект → Project configuration → Developer settings → Continuous deployment → Repository и подключи GitHub-репозиторий. Если интерфейс не позволяет привязать существующий сайт, НЕ создавай второй сайт с другими доменами без необходимости — сначала уточни способ переподключения.
3. При сборке Netlify должен обнаружить папку `netlify/functions` и опубликовать функции.
4. Убедись, что в Deploys есть статус `Published`, затем зайди на `https://ТВОЙ-ДОМЕН.netlify.app/admin-payment-check.html`.
5. Введи придуманный тестовый пароль и нажми «Создать тестовый платёж».
6. На тестовой платёжной странице должно быть обозначено, что это Sandbox. Настоящие деньги НЕ вводи и не отправляй.
7. После симуляции оплаты нажми «Проверить статус». Статус `paid` означает ТОЛЬКО успешный sandbox-тест.

Официальные инструкции Netlify: https://docs.netlify.com/build/functions/get-started/

## Webhook (только после публикации функций)

Endpoint, который проверяет подпись: 
`https://ТВОЙ-ДОМЕН.netlify.app/.netlify/functions/rollypay-webhook`

Для тестового события функция сверяет `X-Signature` с HMAC-SHA256 от `X-Timestamp + '.' + rawBody` и пишет безопасную краткую запись в Netlify function logs.

**Не устанавливай этот URL в действующую кассу с реальными клиентскими платежами до полной продакшен-интеграции.** Функция намеренно отвергает реальные платежи кодом HTTP 503: пока нет постоянной базы заказов, сверки реальной суммы/валюты, контроля повторов и выдачи H1Cloud. Из-за такого ответа реальные платежи не будут обработаны системой Vainah VPN.

## Для подключения реальных покупок ещё необходимы

- настоящие рублёвые цены тарифов и договорённость о составе услуг;
- постоянная БД заказов/пользователей (без неё нельзя безопасно учесть каждый платёж один раз);
- привязка заказа к конкретному владельцу VPN-подписки;
- серверный H1Cloud provisioning и проверка доступа пользователя;
- сверка `payment_id`, `order_id`, суммы, валюты, статуса и отмен/возвратов;
- идемпотентность — однократная выдача доступа;
- тестирование на sandbox и затем контролируемый запуск с учётом правил платёжного провайдера.

Для цифровых товаров/услуг **внутри Telegram Mini App** действуют требования оплаты через **Telegram Stars**. Rollypay здесь предназначен для самостоятельного сайта за пределами Telegram.

## Большой сайт Vainah VPN — обновление

Маркетинговые и информационные разделы расположены в папке `site/`:

- `index.html` — большая главная со слоганом «Твоё соединение. Твои правила»;
- `features.html` — возможности;
- `plans.html` — тарифы (покупка по-прежнему только в существующем Telegram-боте);
- `servers.html` — выбор локаций и разъяснения;
- `devices.html` — устройства;
- `guide.html` — инструкции подключения;
- `security.html` — безопасность;
- `speed.html` — скорость и стабильность;
- `troubleshooting.html` — пошаговое устранение ошибок;
- `help.html` — FAQ;
- `contact.html` — поддержка;
- `about.html`, `privacy.html`, `terms.html` — информация и правила.

Новые страницы используют `site/assets/main.css` и `site/assets/main.js`. Netlify публикует всю папку `site`, настройки указаны в `netlify.toml`.

**Оплата не дорабатывалась** в этом обновлении: Rollypay Sandbox остаётся только для тестирования, а реальные платежи и автоматическая выдача VPN через публичный сайт не включены. Реквизиты и секреты хранятся только в переменных окружения хостинга, а не в репозитории.

Проверки локальных путей новых страниц и наличия стилей добавлены в `tests/site.test.mjs`; запускать через `npm test`.


## Новая общая подписка сайта и Telegram (отдельная ветка, ещё не запущена)

В ветке `feature/telegram-linked-checkout` разработаны:

- `site/checkout.html`: выбор тарифа, проверенный Telegram Login Widget, платежи **на отдельном сайте** через RollyPay (выключены до настройки);
- `site/account.html`: панель собственной подписки по подтверждённому Telegram ID;
- `site/payment-result.html`: статусы заказа и отправки доступа;
- PostgreSQL-таблицы заказов, подписок и привязок;
- защищённая проверка RollyPay webhook/API и доставка VPN-ссылки через @Vainahvpn_bot после подтверждённой оплаты;
- отдельный флаг `VAINAH_LIVE_CHECKOUT`: реальные платежи **по умолчанию выключены**.

Руководство: **[SUBSCRIPTIONS-SETUP.md](SUBSCRIPTIONS-SETUP.md)**. Нельзя включать оплату до проверки реальной панели H1Cloud, секретов, схемы Telegram-клиентов, цен, callback URL и базы данных. Пока ветка не объединена с `main`, публичный Netlify сайт не изменится. Бот под управлением H1Cloud нельзя считать автоматически синхронизированным, если у него другая база или имена пользователей.

В Telegram для цифровых VPN-услуг действуют правила Telegram Stars; RollyPay предусмотрен только на самостоятельном сайте вне Mini App.
