# Vainah VPN Native macOS — Xcode packet-tunnel foundation

This is a **separate SwiftUI native macOS app**, not the Electron macOS UI
preview. It shares the strict VLESS REALITY URL parser and Keychain profile
storage implementation with iOS, and contains a proper
\`NEPacketTunnelProvider\` extension target.

For now the extension **fails closed**: a fully working native VLESS packet
engine with platform-specific TUN fd and bidirectional packet forwarding
must be embedded and tested before it may complete VPN startup successfully.

The Xcode project is generated by XcodeGen. GitHub only performs unsigned
compilation; it does not produce a signed macOS app or notarized DMG.
Signing with macOS NetworkExtension entitlements, a real core and physical
device verification for encrypted egress/DNS/IPv6 are mandatory before release.

The existing functional Android APK and the current website are unchanged.
