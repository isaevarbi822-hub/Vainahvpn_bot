КОРОТКИЕ ОТВЕТЫ

Частые вопросы.

Почему кнопка подключения пока не работает?

Встроенный VLESS-движок ещё не реализован. Пока нет шифрованного туннеля, программа не должна показывать, что интернет защищён.

Где посмотреть купленную подписку?

Открой «Мой кабинет» и авторизуйся на настоящем сайте. Купленные через Telegram услуги могут быть привязаны к Telegram-аккаунту.

Это платная установка?

Нет. Этот предпросмотр интерфейса ничего не покупает и не списывает деньги. Реальные тарифы показаны для знакомства.

Когда будет реальное VPN-подключение?

После интеграции и проверки совместимого H1Cloud/VLESS-движка на Windows и macOS. До этого момента приложение предназначено для изучения интерфейса.
