# Vainah VPN — большая экосистема: четыре платформы и один сервис

**Статус на 2026-10-20: только интерфейсы и платформенные заготовки;
ни одна из текущих тестовых сборок НЕ защищает трафик через VPN.**

## Что есть (реально)

| Направление | Технология | Доступность | Сетевой движок |
|---|---|---|---|
| Публичный сайт | HTML/JS + Netlify Functions | production сайт продолжает работать | платформа H1Cloud — существующая |
| Android | Kotlin, Android VpnService | APK UI Preview | ещё нет |
| iPhone/iPad | SwiftUI, NetworkExtension | исходники и симуляторная сборка | ещё нет |
| Windows | Electron, локальный UI | EXE UI Preview | ещё нет |
| macOS Intel и Apple Silicon | Electron, локальный UI | DMG UI Preview | ещё нет |

### Главное правило честности
Кнопка «Подключиться» НЕ может показывать «Защищено», пока **реальный**
туннель не отправляет и не принимает зашифрованные пакеты через
проверенную систему. Подписка H1Cloud в виде HTTPS-ссылки сама по себе
не является рабочим системным VPN-туннелем.

## Направление архитектуры (следующие итерации)

1. **Единая дизайн-система.** Стабильная фирменная палитра и V-логотип,
   русские простые тексты, масштабирование окна, клавиатура, экранные
   читатели, уменьшение движения, многоплатформенные визуальные тесты.
   Сохранить нативные особенности каждой платформы.

2. **Один проверенный каталог.** Цены/сроки/лимиты серверные; приложения
   отображают подписанную безопасную информацию, не позволяют менять
   стоимость на клиенте. Платежи на сайте по-прежнему отключены
   до отдельного проверки мерчанта и доставки.

3. **Аккаунты без утечки заказов.** Telegram, Clerk и Яндекс — реальные,
   проверенные провайдеры; собственное приложение должно обменивать
   только серверно проверенные сеансы по подходящему нативному потоку
   входа. Заказы доступны лишь владельцу. Связывание аккаунтов только
   после проверки владения обоими аккаунтами.

4. **H1Cloud API-шлюз.** Endpoint «мой VPN» выдаёт профиль лишь после
   подтверждения подписки. Не хранить PANEL_API_TOKEN, данные платежей,
   чужие профили или подписочные ссылки в мобильном/desktop-клиенте.
   Поддержать безопасную ротацию, отзыв и лимиты устройств.

5. **Настоящий VPN.** Отдельный аудированный движок для VLESS и
   конкретных настроек H1Cloud, контролируемая передача пакетов и
   разрешения ОС. Android — VpnService. Apple — Packet Tunnel
   NetworkExtension. Windows — корректная VPN/TUN интеграция с
   подписанными компонентами. macOS — расширение с entitlements.
   Отдельный протокол безопасности и лицензирование движка.

6. **Надёжность.** Интеграционные тесты DNS, IPv6, TCP/UDP, утечки,
   утрата связи, смена Wi‑Fi, спящий режим, отмена/пауза подписки,
   аварийное завершение, восстановление соединения и отмена разрешений.

7. **Знакомые пользователю функции.** Экран «Подписка», состояние
   сервера, срок действия, список устройств, уведомления об истечении,
   мастер решения проблем, диагностические коды без секретов и
   защищённые обновления, зависящие от платформы.

8. **Выпуски и подпись.** Отдельные каналы: nightly/internal QA,
   ограниченное бета-тестирование, подписанный production выпуск.
   Windows Authenticode, Mac Developer ID/notarization, iOS
   TestFlight/App Store, Android надёжное подписывание/Play Store.
   Пользователям не предлагается отключать защиту ОС ради тестов.

9. **Масштабирование серверной части.** Показатели успешного подключения
   (без раскрытия трафика), очередь событий доставки, устойчивость к
   повторным платежным webhook, лимиты, резервирование, проверка
   H1Cloud, наблюдаемость без VPN-ключей и стабильные версии API.

10. **Контроль качества и приватности.** Единый сценарий «первый запуск»,
    минимум разрешений, политика хранения данных, проверка зависимостей,
    конфиденциальность VPN-трафика, доступность сайта и приложений,
    понятные условия услуги.

## Что не меняется при этой работе

- Рабочий Netlify-сайт **не перезаписывается**: изменения в GitHub draft PR.
- Telegram-бот продаёт подписки отдельно; кнопка «Купить через бота»
  на сайт не добавляется.
- Не включается заблокированный production checkout.
- Нет чужих ключей/токенов, фиктивных «подключено» и изобретённых заказов.
- Тестовые неподписанные APK/EXE/DMG не являются массовым production.
- Для подписи/магазинов могут потребоваться взрослый владелец и
  необходимые юридические документы; не обходить возрастные правила.
